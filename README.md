# WISDOM NETWORK

WISDOM NETWORK is a collaborative knowledge ecosystem designed to connect ideas, people, and tools around learning, decision-making, and responsible innovation.

## Vision

We are building a platform where insight becomes action. The network brings together:

- knowledge sharing
- community intelligence
- human-centered product thinking
- practical systems for collaboration

## Project Status

This repository is the current foundation for the WISDOM NETWORK project. It includes a simple landing page scaffold and starter documentation for the next build phase.

## Structure

- `index.html` — landing page
- `styles.css` — visual design and layout
- `script.js` — UI interactions
- `.gitignore` — ignores common local/editor files

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
