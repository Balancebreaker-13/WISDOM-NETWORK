# Archived repository: Bitcoin Wallet Post-Quantum Migration

This directory preserves the legacy research repository previously maintained under:

- https://github.com/Balancebreaker-13/bitcoin-wallet-post-quantum-migration

## Purpose

The archived project focused on evaluating Bitcoin wallet migration strategies in a post-quantum cryptography environment, including hybrid ECC + PQC approaches, wallet security modeling, and engineering validation work.

## Status

The project was a research and validation effort, not a production-ready wallet or deployable financial system. The repository documentation explicitly stated that it was intended for research, prototyping, and validation rather than live deployment.

## Why it is archived here

WISDOM NETWORK is now the active main project repo. This archive preserves the legacy work without losing the technical context or prior research effort.

## Legacy highlights

- hybrid ECC + PQC wallet concepts
- Bitcoin wallet migration research
- cryptographic prototype and validation work
- benchmarking and proof-of-concept testing material
- documentation covering migration path and security considerations
